# Glossary

Use these terms consistently in prompts, docs, and code review.

## Project Terms

- Albion API: this full-stack repo.
- Client: `client/`, the Next.js frontend.
- Server: `server/`, the Bun/Elysia backend.
- Item metadata: static Albion item/location data from `ao-data/ao-bin-dumps`.
- Price data: market rows from Albion Online Data Project.
- Gold data: gold price history from Albion Online Data Project.
- Recommendation: city ranking generated by `PriceAdvisoryService`.
- Market snapshot: per-city aggregate generated from item price rows.
- OAuth state: MongoDB-stored PKCE state for Google login.
- `logged_in`: non-httpOnly cookie used by frontend middleware.
- `auth-token`: auth token name used by current auth context/cookies.
- `auth_token`: auth token key read by Axios config; known mismatch.

## Main Backend Names

- `itemController`: item list, item details, price routes, cache routes.
- `ItemRepository`: metadata, price fetching, search indexing, pagination.
- `goldController`: `/api/gold`.
- `GoldRepository`: gold API fetch and cache.
- `OauthController`: Google OAuth routes.
- `OAuthService`: PKCE, token exchange, user upsert.
- `DatabaseService`: users and OAuth state data access.
- `recommendationController`: market snapshots and recommendation routes.
- `PriceAdvisoryService`: aggregation and city scoring.
- `TTLCache`: simple in-process cache.

## Main Frontend Names

- `axiosInstance`: shared Axios client.
- `itemApi`: frontend API wrapper for item/gold calls.
- `ItemSearch`: main search and city price UI.
- `AuthContext`: client auth state and login/logout actions.
- `GoldLineChart`: Chart.js line chart wrapper.
